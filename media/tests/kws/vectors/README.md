# Keyword frontend test vectors

Synthetic inputs and the features `../frontend_ref.py` computes for them: the oracle for the C++ keyword frontend. No
vendor data: every signal is generated by `../make_vectors.py`.

## Layout

Each `<name>.f32` is a flat array of little-endian float32 values:

| Offset (values) | Count | Content |
|---|---|---|
| 0 | 4 | header: format version (1), `n_samples`, `n_frames`, `n_mels` (40), each an exact integer |
| 4 | `n_samples` | the input: int16 samples stored as float32 (exact), 16 kHz mono |
| 4 + `n_samples` | `n_frames * n_mels` | the features in dB, frame-major (frame 0's 40 values first) |

- `n_frames` = (`n_samples` − 640) / 160 + 1.
- `n_samples` is a multiple of the 1280-sample fragment, so streaming the input fragment by fragment must give the same
  frames as processing it whole.

| File | Signal |
|---|---|
| `silence.f32` | zeros: every feature is the −100 dB floor |
| `sine-1k.f32` | 1 kHz at half scale |
| `two-tone.f32` | 250 Hz + 3150 Hz, quarter scale each |
| `chirp.f32` | linear 50 Hz → 7950 Hz over 1.28 s |
| `noise.f32` | uniform noise in [−8192, 8191] from a fixed LCG |
| `quiet.f32` | ±1 LSB noise from a fixed LCG (features about −48…−70 dB) |
| `edge-full-scale.f32` | a square wave alternating −32768 and +32767 |

## Comparing

- Compare the input samples **exactly** (they are int16 values).
- Compare the features **by tolerance, never by hash or bit pattern**: absolute error ≤ **1e-3 dB** per value.
  - Why: the oracle computes in float64 and rounds to float32, while the device pipeline is float32 throughout.
  - A float32 pipeline in numpy (float32 scaling, window, FFT, power, filterbank and log) stays within 1.2e-4 dB of
    these files on every vector, the largest gap on `chirp`. 1e-3 dB leaves room for another FFT implementation's
    rounding.
- The `silence` features must be exactly −100 dB (the 1e-10 floor).

The files are byte-stable when regenerated on one machine, but another numpy version, BLAS or platform may change the
last bits of the features. That is why consumers compare by tolerance.

## Regenerating

From the repo root, with numpy installed:

```sh
python3 -I media/tests/kws/make_vectors.py
```

The script writes `media/tests/kws/vectors/*.f32`, or the directory given as its first argument, and fails if the
streamed and whole-signal features disagree. After an intended frontend change, regenerate, check the diff with the
same tolerance rule, and commit the new files.
